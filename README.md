# SASG-PolSAR

Official repository for the paper:

**Multitemporal PolSAR Superpixel Generation via Boundary-Guided Region Growing and Refinement**

This work proposes a structure adaptive superpixel generation method for multitemporal polarimetric synthetic aperture radar (PolSAR) images. The method integrates boundary aware seed redistribution, directional region growing constraints, multitemporal polarimetric similarity, dynamic scale constraints, and boundary refinement within a priority queue driven region growing framework.
